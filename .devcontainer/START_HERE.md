# Accent Coach is starting

**The app opens in a separate browser tab**, not here. This window is just the machine it runs on.

1. **First time?** Setup takes 2–3 minutes. Watch the **Terminal** panel at the bottom
   (open it with **Ctrl + `**) until it says
   `Accent Coach is running at http://localhost:8765/`.
2. A new tab should open by itself. If it doesn't (or your browser blocked a pop-up):
   click the **Ports** tab next to Terminal → hover **Accent Coach (8765)** →
   click the **globe icon** (Open in Browser).
3. In the app, allow the microphone when asked.

**Nothing running?** Type this in the terminal and press Enter (it finishes any
incomplete setup, then starts the app):

```
bash .devcontainer/start.sh
```

Keep this codespace open while you practice; you can close this file.
